# DevdudeX's (and Jcau8's) Custom UI for Lonely Mountains Games
This is a system for creating custom modded UI in the games Lonely Mountains: Downhill / Snow Riders running on the Unity game engine.

![Mod menu preview](/images/banner.png?raw=true)

# How can I use this in my project?
To get started, download the latest `LMUI.dll` under the "Releases" tab. Place it in your melon loader mods folder, and you are ready to start using it in your mods!  

If you are looking for an example on how to use LMUI in your mod, go check out my [simple mod menu for Lonely Mountains: Downhill](https://github.com/jcau8/LMUI-Example).    
Any queries or questions, make an issue either here or in the example project.
